# Reaction Journey Help

Current instructions for members, moderators, and administrators. Use the decimal hierarchy to locate sections, topics, and steps.

## 1. Member help

### 1.1 Getting started

#### 1.1.1 Sign in, navigation, and app updates

1.1.1.1 Use Continue with Google or Email me a sign-in link on the welcome page. Open the newest email link sent to the address you entered. Your first verified sign-in creates your account.
1.1.1.2 The account button opens Your account; Sign out ends this browser session. Set your display name and profile image in My Profile & Activity. Your avatar opens that page.
1.1.1.3 Use the side navigation on larger screens. On smaller screens, use the bottom navigation and More for the remaining pages and actions. The MS Journey logo opens the official-video archive.
1.1.1.4 Install app offers browser-supported installation or instructions for adding Reaction Journey to your home screen. Installation is optional and does not create another account.
1.1.1.5 When An app update is ready appears, finish your edits before choosing Update now. If the interface still looks outdated, refresh the page; on Windows, Ctrl+Shift+R reloads it. The public About page and policies are available before sign-in.

#### 1.1.2 Public About page, privacy, and support

1.1.2.1 The sign-in page links to a public About overview, YouTube import explanation, Privacy Policy, Terms, and contact address. The member catalog and personal choices require sign-in.
1.1.2.2 Reaction Journey is an independent fan community, not an official Missioned Souls or YouTube service. Reaction videos remain hosted by YouTube; MS Journey also links to Facebook and other listed sources.
1.1.2.3 Use Contact for a private in-site support request or email contact@reactionjourney.com. Include the exact error, time, and direct video or channel link. Do not send passwords, API keys, or Google tokens. Support Reaction Journey is an optional PayPal donation link.

#### 1.1.3 Troubleshooting and support

1.1.3.1 If a view is empty, clear search/date/numeric filters, check Hide Shorts and Only confirmed reactions, and verify your follows and Reactors → Hidden reactors. Also try All reactions, enable Include Shorts, and check Only confirmed reactions and other filters in Customize feed.
1.1.3.2 If Following shows everything, check whether Missioned Souls is your only follow or whether All follows is selected.
1.1.3.3 If a favorite is missing, check Favorites and hidden reactors. A pending, rejected, excluded, or unavailable catalog record will not appear simply because its title was corrected. Contact a moderator with the direct video URL.
1.1.3.4 After an update, hard refresh with Ctrl+Shift+R on Windows. My Feed loads independent account and catalog reads together and caches eligible catalog responses; filters still determine which videos appear.
1.1.3.5 If sign-in loops, use the latest email link and use Contact for sign-in support.
1.1.3.6 For Catalog, Social service, or Performer management temporarily unavailable, retry later and send the exact message and time through Contact.
1.1.3.7 A database quota error cannot be fixed by a browser refresh.
1.1.3.8 If new videos seem to be missing, use Contact with their direct video links and the time you checked.
1.1.3.9 Support Reaction Journey opens the voluntary PayPal donation link.
1.1.3.10 YouTube Terms opens YouTube’s terms.
1.1.3.11 Reaction Journey is an independent fan community; no affiliation is implied.
1.1.3.12 Most viewed excludes official Missioned Souls uploads. Newest reactor and Highest ranked reactors each show one latest matching reaction per channel; this can produce a much shorter list than Newest uploads. Check the selected sort before treating a missing older reaction as a catalog problem.
1.1.3.13 Following groups and both pages’ search controls start collapsed. Click their title or magnifying-glass button to reveal them. A completed YouTube import uses Check for new matches for another preview; manage disconnection in Manage YouTube connection.

### 1.2 Feed and videos

#### 1.2.1 My Feed: tabs, search, and sorting

1.2.1.1 All reactions is the general feed, subject to your filters. It can also include official Missioned Souls YouTube uploads, labeled MS JOURNEY / Official upload or Official Short. These are separate from reactor reactions; View in MS Journey opens their archive.
1.2.1.2 New today includes videos discovered today or published today, using your browser’s local date. An older upload may be newly discovered. Following uses your account’s follows; Favorites contains individually saved videos; Community finds contains accepted community submissions.
1.2.1.3 Click the magnifying-glass button, Show search and filters, to reveal or hide search and performer controls. Search matches titles, channel names, and known songs. Include Shorts controls Shorts visibility. Customize feed opens additional date, rating, subscriber, watched, and other filters.
1.2.1.4 Newest uploads orders matching videos by their YouTube publication date, newest first. Highest rated uses community video ratings. Most discussed uses comment counts. Reactor size uses the channel’s subscriber count.
1.2.1.5 Most viewed lists reaction videos by recorded view count, highest first. Official Missioned Souls channel uploads are excluded. Counts are recorded snapshots and may differ from the latest YouTube totals.
1.2.1.6 Newest reactor follows the Reactors page’s Newest Reactor order: the upload date of each channel’s oldest cataloged Missioned Souls reaction, newest first. It shows one latest matching reaction per reactor. Finding an older reaction can move a channel down; unknown dates sort last.
1.2.1.7 Highest ranked reactors orders channels by community reactor rating and shows only the latest matching reaction from each reactor. This is the channel’s 1–100 score, separate from the video’s 1–5 rating. Official uploads are excluded from this and Newest reactor.
1.2.1.8 For both one-video-per-reactor sorts, latest means the newest upload that passes your current feed filters. A date, search, Shorts, Following, or other filter can select an older matching reaction or exclude a reactor entirely. Other sorts can show multiple videos from one channel.
1.2.1.9 Load more reactions expands the result list. Catalog totals and the filtered video count describe different things. Saved views using a retired sort fall back to Newest uploads. Discovery date can still be displayed on cards; it is not a sort-menu choice.

#### 1.2.2 Reaction cards, watch lists, ratings, and comments

1.2.2.1 Open a reaction’s discussion to view its details, rate it, comment, or request removal. Report an incorrect Short/full-length designation using Other and explain the correction.
1.2.2.2 Open the YouTube link to watch at its source; preview playback follows YouTube and browser rules.
1.2.2.3 Use the watch-status selector to track a video’s status and the heart to add or remove a Favorite.
1.2.2.4 Favorites and Following are different: a Favorite saves an individual video; a follow selects future matching uploads.
1.2.2.5 Rate 1–5 for reaction quality and insight, then Save rating.
1.2.2.6 Every member’s rating has equal weight; changing your rating does not earn more points.
1.2.2.7 Trusted Members publish comments and replies directly. Other members submit them for moderator review; pending comments are visible only to their author until approved.
1.2.2.8 Reply starts a response; Edit publishes directly for Trusted Members or resubmits for review when approval is required; Delete removes your own contribution.
1.2.2.9 Like, Block, and Report appear where available.
1.2.2.10 Blocking hides that member’s content for you.
1.2.2.11 For Request video removal, select Wrong performer, Not a reaction, Short or excerpt, Video unavailable, Duplicate listing, or Other relevance issue; explain the problem and Send removal request.
1.2.2.12 The listing remains until a moderator acts.
1.2.2.13 Disagreement or a low rating alone is not grounds for removal.

#### 1.2.3 Saved Views

1.2.3.1 Save current feed or Save as new view opens the naming dialog.
1.2.3.2 Enter a descriptive name and Save view, or Cancel.
1.2.3.3 Open view restores its filters and layout.
1.2.3.4 Make default selects the saved view for future visits; Delete removes the saved view without deleting videos, favorites, or follows.
1.2.3.5 Saved views save settings, not a frozen copy of results: newly cataloged matching videos can appear later.

#### 1.2.4 Appearance & preferences / Customize feed

1.2.4.1 Both buttons open Make it yours.
1.2.4.2 Changes preview immediately.
1.2.4.3 Save as default writes your preferences to your account for other devices.
1.2.4.4 Save as new view stores a named combination; Close dismisses the drawer and is not a Save button.
1.2.4.5 Appearance includes Theme (light/dark/system), Accent (teal/blue/violet), Feed layout (cards/compact/large/table), Density (compact/standard/spacious), Thumbnail size, and Cards per row (2–5).
1.2.4.6 Organize your feed includes Group by (none/performer/reactor/song/genre/date/source), Default landing view (All reactions/New today/Favorites/Following/Community finds), Default saved view, Uploaded in the past, From date, Through date, Minimum subscribers, Minimum rating, and Reactor/Song/Genre contains.
1.2.4.7 Hide Shorts, Hide watched videos, Only confirmed reactions, and Only followed reactors are additional filters.
1.2.4.8 Only followed reactors applies even outside Following.
1.2.4.9 Detail toggles select Upload date, Community rating, Reactor subscribers, Views, Likes, Comment count, Performer, Song, Genre, and Discovery date.
1.2.4.10 Autoplay requests automatic preview playback; browser restrictions can prevent it.
1.2.4.11 A default saved view can override other default settings when opened.
1.2.4.12 The Following includes choice is a temporary browsing choice, not currently stored with saved preferences.

#### 1.2.5 MS Journey: official video archive

1.2.5.1 Open MS Journey from navigation or the logo link. It catalogs the band’s official performances, Shorts, vlogs, and other videos separately from reactor reactions. Official YouTube uploads can also appear as clearly labeled cards in My Feed; Most viewed, Newest reactor, and Highest ranked reactors are reaction-only views.
1.2.5.2 Browse All videos, Facebook only, By year, official playlists, and other collections in the archive navigation. On smaller screens, use Playlist or category. Categories overlap, so their counts should not be added together. Facebook only omits entries marked as also having a YouTube version.
1.2.5.3 Click the magnifying-glass button, Show search and filters, to open search, Year, Source, and Collection. Click it again to hide those controls. Include Shorts stays beside the results; Clear filters resets the category and filters and turns Shorts on.
1.2.5.4 Collection offers All · newest first, Ten most current videos, and Top 10 by views, likes, or comments. Unknown counts are omitted from numeric rankings; unknown dates are omitted from Ten most current videos. Year uses the publication date.
1.2.5.5 Top 10 · views gained in 1 day, 1 week, or 1 month measures observed growth over 24 hours, 7 days, or 30 days. It needs a recent count and a baseline near the period boundary. An empty ranking can mean insufficient history rather than zero views; it is not each video’s first day after release.
1.2.5.6 Watch on YouTube, Facebook, or another listed source opens that original video. The archive may be incomplete; counts are dated snapshots. Load more videos expands results. Use the archive navigation and filters to explore the videos.

### 1.3 Reactors and following

#### 1.3.1 Following and the reactor directory

1.3.1.1 Open Reactors to search channel names and choose a sort order and 10, 25, 50, or All reactors per page. Previous and Next move through the list. Click a channel name to open it on YouTube.
1.3.1.2 Use + Follow to follow one reactor; ✓ Following removes that follow when clicked. Follow All Reactors follows all channels matching your current reactor search and performer selection, across every page. It skips existing follows and hidden reactors. Progress appears below the buttons.
1.3.1.3 Clear All Following asks for confirmation and removes every reactor follow in your account, including channels outside the current search and hidden channels. Song and performer follows, saved groups, ratings, and hidden choices are retained. Go To Following opens the Following page.
1.3.1.4 Following lists reactor and song follows, with performer follows at the bottom. Unfollow removes one item. Enter a song title and select Follow song; matches use the exact normalized catalog song name when available, otherwise a whole song-title phrase in the video title. Song follows can include unfollowed channels.
1.3.1.5 View followed reactions on My Feed opens My Feed’s Following tab. Open the search-and-filters button to see Following includes. Its default shows only followed reactors and songs. Choose Include followed performers to also show videos matching a followed performer. Empty follows stay empty. Other feed filters still apply.
1.3.1.6 Official uploads follow the same reactor, song, and optional performer rules. Saved groups use only reactor and song follows; an empty active group shows no videos. Favorites saves individual videos; Following selects matching uploads. The Follow performer button controls Missioned Souls, while Manage follows opens Following when All performers is selected.

#### 1.3.2 Following groups

1.3.2.1 On Following, click the Following groups title to open its controls; click again to hide them. It starts collapsed. Groups are private combinations of reactor and song follows, separate from Saved Views.
1.3.2.2 Build the follows you want, enter a New group name, and select Save current follows as new group. You can save up to 50 groups with names of 1–60 characters. Creating a group does not activate it.
1.3.2.3 Choose a Saved group to switch automatically. Your active group’s current follows are saved when you switch away. If no group is active, save your current follows as a group first if you want to keep them; switching can ask for confirmation.
1.3.2.4 Rename changes the selected group’s name. Delete group asks for confirmation, removes that saved group, and leaves current follows in place. Saved groups are listed alphabetically.
1.3.2.5 Performer follows, hidden reactors, ratings, favorites, and appearance are account choices outside groups. Hidden reactors stay hidden. An empty active group shows no followed reactions.
1.3.2.6 Tracked YouTube-imported follows stay separate: group snapshots exclude them and group switching preserves them while the connection remains active. Disconnecting YouTube removes tracked imported follows; groups cannot restore those follows.
1.3.2.7 Reactor or song resets save the active group’s current follows before deactivating it. Master Reset keeps saved groups at their last saved snapshot. Choose a saved group later to restore its saved follows. View followed reactions on My Feed opens the filtered Following feed.

#### 1.3.3 Sorting followed reactors and songs

1.3.3.1 Following offers alphabetical, community-ranking, or personal-ranking order for reactors. Songs use alphabetical order or the average community video rating of matching videos. Unrated items sort last; alphabetical order breaks ties. These choices are saved to your account.
1.3.3.2 The Saved group list is alphabetical. Group selection switches automatically; no separate group sort or switch control is needed.

#### 1.3.4 Reactor discussion, ratings, and ranking

1.3.4.1 In Reactors, use Discuss to open a channel discussion. Rate the reactor overall from 1 to 100; 100 is highest. Save records your vote and Clear removes it. Each member has one editable vote per channel.
1.3.4.2 Community score is the average member reactor rating, with the number of ratings shown. Community rank sorts highest first; My ranking uses your own votes. Newest Reactor uses the upload date of each channel’s oldest cataloged Missioned Souls reaction. Subscribers and Name A–Z are also available; unrated items sort last in rating sorts.
1.3.4.3 The First reaction date is the oldest cataloged reaction upload, not when the channel joined YouTube or was added to this site. It can move back when an older reaction is found. Unknown dates are labeled and sort last.
1.3.4.4 In My Feed, Highest ranked reactors shows the latest matching reaction per reactor in community-score order. Newest reactor shows the latest matching reaction per reactor in the directory’s newest order. Video ratings use a separate 1–5 scale.
1.3.4.5 Reactor discussion is about the channel; video discussion is about one upload. Comments use 10–2,000 characters. Helpful, Reply, Edit, Delete, Report, and Block appear when applicable. Trusted Members post directly; other comments and edits await approval.
1.3.4.6 Useful reactor and video comments/replies share the +3 Contribution Points award, up to three awards per day. Removed comments reverse their awards. Reactor ratings do not earn video-rating points.

#### 1.3.5 Hide and unhide reactors

1.3.5.1 Use Hide reactor on a reaction card, or Reactors → More → Hide, to hide a channel from your feed, search results, Following, Favorites, and saved feed views.
1.3.5.2 Open Reactors → Hidden reactors and choose Unhide to restore visibility. Follow All Reactors skips hidden channels. Hiding does not remove videos for other people or change your follows, ratings, or watch history.
1.3.5.3 Master Reset clears hidden-reactor choices along with reactor and song follows and reactor ratings. Clear All Following only clears reactor follows; it does not unhide channels.

#### 1.3.6 Suggest a reactor or recommend removal

1.3.6.1 On Reactors, use Suggest a reactor or recommend removal. More → Recommend removal beside a channel fills in that channel’s details.
1.3.6.2 For an addition, supply a UC channel ID or a direct youtube.com/channel/UC… URL, the channel name, and a reason with a Missioned Souls reaction link. Handles are not accepted in this form. Select Send request.
1.3.6.3 My recent requests shows status and moderator notes. Up to five requests per day are allowed; duplicate pending requests are blocked. Requests do not immediately add, remove, or hide a reactor. Use More → Hide for your personal feed.

#### 1.3.7 Connect YouTube and import subscriptions

1.3.7.1 Open Reactors and expand Import YouTube subscriptions. Connect YouTube starts a separate Google authorization flow with read-only subscription access; it is optional and separate from signing in to Reaction Journey.
1.3.7.2 After connecting, a preview opens. Use Preview subscriptions to check again while connected. Review matched catalog reactors in batches of up to 100, adjust the checked items, then use the Import button showing your selected count. The next batch appears automatically.
1.3.7.3 Imported follows are saved in a separate system-managed Following group named YouTube imports. This keeps imported subscriptions separate from your active personal follows.
1.3.7.4 Already followed, hidden, and outside-catalog channels are counted separately. Unselected reactors are skipped for this preview and can be reviewed again later. Finish for now closes review and keeps batches you already confirmed; Cancel preview stops a pending preview.
1.3.7.5 Check for new matches starts another check after a completed review. Nothing is automatically followed in the background, and your YouTube subscriptions are never changed.
1.3.7.6 Expand Manage YouTube connection and select Disconnect and delete imported follows to remove tracked follows created by that connection and revoke its access. Manual follows, ratings, favorites, and hidden choices remain. Older imports made before tracking need manual review in Following.
1.3.7.7 The server stores an encrypted Google refresh token, checks permission daily and before imports, and reads subscriptions only on request. The browser receives channel IDs for review, not Google tokens. The complete subscription list is not saved. Revoked or expired permission can remove the connection and its tracked follows. See the Privacy Policy and Google account connections link for details.
1.3.7.8 If Google reports an error, send the exact message and site address through Contact. You can still follow reactors manually or use Follow All Reactors without a YouTube connection.

#### 1.3.8 Clear follows and Master Reset

1.3.8.1 Reactors → Clear All Following and Following → Reset all reactor follows both ask for confirmation and clear all reactor follows, including hidden channels and tracked imported follows. They do not clear song or performer follows, hidden choices, ratings, or YouTube subscriptions.
1.3.8.2 Reset all song follows clears only song follows. Separate reactor or song resets save the active group’s current follows and deactivate it; saved groups remain available. Tracked imported follows are not stored in groups.
1.3.8.3 At the bottom of Following, expand Advanced: Master Reset, select Master Reset…, and read the confirmation. It clears reactor follows, song follows, hidden reactors, and reactor ratings together.
1.3.8.4 Master Reset preserves saved groups at their last saved snapshot, video ratings, performer follows, Favorites, watch status, appearance, account settings, and earned points. Groups cannot restore hidden choices or ratings.
1.3.8.5 After clearing reactor and song follows, the default Following feed stays empty. Performer-wide coverage requires Include followed performers and is unavailable inside saved groups. After clearing hidden reactors, their eligible videos may appear again. These actions affect your Reaction Journey account, not your YouTube subscriptions or the source videos.

### 1.4 Community and account

#### 1.4.1 Chat Rooms and Mentions

1.4.1.1 Choose a room to open its messages.
1.4.1.2 Send message posts the text you entered; use @ followed by a member’s full display name for a mention.
1.4.1.3 Messages refresh approximately every five seconds while the chat page is active and visible.
1.4.1.4 Room badges show unread activity; the active count reflects recent presence, not total membership.
1.4.1.5 Chat does not earn contribution points.
1.4.1.6 Own-message Edit/Delete and other-message Reply/Like/Block/Report controls appear when applicable.
1.4.1.7 Mentions collects matching chat and comment mentions; Open conversation opens the room or video discussion.
1.4.1.8 No personal information, harassment, or spam.
1.4.1.9 Being muted prevents posting until the restriction expires or a moderator removes it.

#### 1.4.2 My Profile & Activity and submitting reactions

1.4.2.1 In My Profile & Activity, choose a Profile icon and Background color, preview the result, then use Save display name to save your profile. Initials returns to the initials icon. Contribution badges remain separate from pictures and icons.
1.4.2.2 Upload profile picture accepts JPG, PNG, or WebP up to 10 MB. The image is cropped to a square and resized automatically. Check the preview and use Save display name to save it; selecting a file alone does not upload it.
1.4.2.3 Your saved picture appears publicly beside your name in discussions, chat, and leaderboards. Remove picture / use icon previews removal; save your profile to confirm it.
1.4.2.4 Save display name updates the public name used on contributions and leaderboards.
1.4.2.5 Submit a reaction opens the missing-video form.
1.4.2.6 Paste a direct YouTube video URL, choose Missioned Souls, explain why it belongs, and click Suggest video.
1.4.2.7 Trusted members publish valid submissions directly and earn points within daily limits. Other submissions await moderator verification. Duplicates, already pending records and exclusions can be rejected.
1.4.2.8 Your contributions and review decisions shows outcomes and moderator notes; Your recent points shows awards.
1.4.2.9 Performer recommendations are closed because Reaction Journey is dedicated to Missioned Souls.

#### 1.4.3 Contribution Points & Trusted Member status

1.4.3.1 First rating of a video: +1, maximum 10 awards/day. Useful comments and replies: +3, maximum 3 combined awards/day. Valid missing reaction submissions: +20, maximum 5/day. Verified catalog correction/removal reports: +10, maximum 5/day. The correction rate applies to new awards; earlier awards keep their original amounts.
1.4.3.2 Trusted members publish reactions, comments and replies directly and earn points immediately. Other members need moderator approval to publish and earn points. All correction/removal reports require moderator verification, including reports from trusted members.
1.4.3.3 Daily limits reset at midnight UTC. Direct posts count on posting date; reviewed contributions count on approval date. Duplicate discoveries, rating edits, chat and moderator self-approvals earn no additional points. Each contribution earns at most one award.
1.4.3.4 Trusted edits retain earned points and do not create a second award. Removed comments reverse their points. Editing a comment while approval is required sends it back for review and reverses its existing award.
1.4.3.5 After three separate currently accepted contributions verified by another moderator, a member is flagged for trust review. Ratings, direct unreviewed posts, rejected/hidden items and self-approvals do not count. A moderator checks quality and accuracy before granting Trusted Member status; three approvals do not grant trust automatically.
1.4.3.6 Moderators can revoke Trusted Member status with a reason. The member can continue browsing and submitting through approval. A posting mute temporarily prevents posting even for trusted members. Revoking trust does not remove previously published posts or point badges.
1.4.3.7 Existing trusted members keep their access during the transition. The former reputation score no longer controls privileges or earns new awards; its history is retained in the Historical reputation archive.
1.4.3.8 Badges recognize Contribution Points: Novice 0–24, Contributor 25–99, Reaction scout 100–249, Catalog curator 250–999, Community champion 1,000+. Badges appear beside names and update with point adjustments or reversals. They do not grant trust or moderator powers. Points have no cash value and do not weight video ratings.
1.4.3.9 Open Points & Trust to see your posting status, moderator-approved contribution count, point weights, badge legend and leaderboard. My Profile & Activity shows recent point awards.

### 1.5 Catalog information

#### 1.5.1 Discovery status & catalog coverage

1.5.1.1 Expand this panel in My Feed to see the last discovery run, recent batches, recent-upload coverage, and history backlog.
1.5.1.2 Channels checked in the past 24 hours measures successful recent-upload checks among eligible Missioned Souls channels; it is a rolling window and can fall when older checks expire.
1.5.1.3 Historical pages are separate and do not count as fresh coverage.
1.5.1.4 Channels held outside routine discovery retain their records. Confirm Missioned Souls reaction evidence before approving a pending match; approval can enable an ordinary held channel. Paused, retired, and official channels retain their protected scope.
1.5.1.5 Recent failures, retry times, channel scopes, and discovery-delay samples help explain incomplete coverage. The last run is not proof of a full catalog cycle.
1.5.1.6 A succeeded run completed its allocated work, not the entire catalog.
1.5.1.7 A partial run can still check channels and add videos while retaining history or stopping at a budget.
1.5.1.8 Newly cataloged IDs are newly stored video IDs; their upload dates may be old.
1.5.1.9 Recent/history/performer-search counters identify their sources.
1.5.1.10 API calls count request attempts, not Google’s definitive quota usage.
1.5.1.11 Elapsed time is wall time; summed API and database timings can overlap and should not be added to estimate duration.
1.5.1.12 Uploads examined measures processing work, not new reactions.
1.5.1.13 Reactor subscriber statistics refresh in daily batches from YouTube. A count can be stale, rounded by YouTube, or unavailable when hidden; it is not a real-time measurement.
1.5.1.14 Imported statistics are dated snapshots, not real-time YouTube analytics. MS Journey’s official-upload scan and reaction discovery are separate catalogs and use separate progress reports.
1.5.1.15 Scheduled checks and YouTube notifications complement each other; neither guarantees immediate or complete discovery.

## 2. Moderator help

### 2.1 Review and trust

#### 2.1.1 Correct video information and restore a missing video

2.1.1.1 Open Moderator → Video Classification Review. Correct video information is at the top and works before or after approval, even when a saved video is absent from the member feed.
2.1.1.2 Paste its YouTube URL or video ID and select Load video. Check Catalog status, availability, and any Exclusion reason. This tool edits an existing saved video; use submissions or reconciliation for a missing catalog ID.
2.1.1.3 Select Fetch YouTube details to populate the title, channel name, channel ID, and upload date. Verify the video on YouTube, choose Short, Full-length, or Unknown, and enter a correction reason.
2.1.1.4 Save Corrections changes the details and format while preserving the existing review decision and exclusions. It does not automatically publish a rejected or excluded match.
2.1.1.5 After verifying a valid Missioned Souls reaction, select Save Corrections & Restore to deliberately remove its Missioned Souls exclusion and set its match to Confirmed. Restoration requires an existing Missioned Souls match, an available video, and active performer coverage.
2.1.1.6 Restoration retains comments, ratings, and other performers’ decisions. Recent corrections records the reason; the audit stores the before and after details.
2.1.1.7 Reload the video by ID to verify the result. If it still does not appear, clear feed filters and unhide the correct reactor. Changing the channel moves the video to its corrected channel; channel discovery holds and unavailable-video protections remain separate.
2.1.1.8 Before using Restore, confirm the video is a reaction from a reactor channel. Official Missioned Souls videos should remain in MS Journey; restoring an official upload as a confirmed reaction creates an incorrect catalog classification.

#### 2.1.2 Approve member-submitted reactions

2.1.2.1 Open Moderator Queue and find the community submission in the review queue. Select Fetch YouTube details to fill its title, channel, upload date, and suggested format.
2.1.2.2 Open Verify on YouTube to confirm the performer and reaction. Choose Short, Full-length, or Unknown / needs format review; short duration alone does not prove a YouTube Short.
2.1.2.3 Enter a review note, choose Accept, and select Save review. Accepted verified submissions are Confirmed; the selected format is saved. Protected exclusions or unavailable videos can prevent publication.
2.1.2.4 If fetching fails, expand Video details for the manual fallback and supply the correct title, channel name, and UC channel ID. Check the result message and member feed after approval.
2.1.2.5 Use Correct video information for later title or channel corrections and deliberate restoration.

#### 2.1.3 Moderator Queue: review safely

2.1.3.1 This menu is available only to designated moderators.
2.1.3.2 Refresh reloads uncertain matches, submissions, content reports, and performer settings.
2.1.3.3 Open the YouTube link and verify Missioned Souls and the reaction’s actual format before deciding.
2.1.3.4 Approve publishes the selected eligible match; Exclude rejects that match and records its exclusion.
2.1.3.5 Open a published video’s discussion to use Moderator: video format. Select Short, Full-length, or Unknown / needs review, then Save format. Exclude video removes an irrelevant match separately. These controls are available only to moderators. Mark as Short classifies and locks its format; it does not publish or exclude the match. Approve a relevant pending Short separately, or choose Exclude.
2.1.3.6 Previously excluded Shorts lists records excluded by the old Mark as Short action. Check each video, then use Restore & approve as Short to deliberately publish a relevant one. Other exclusions remain protected. It does not delete the video from YouTube.
2.1.3.7 Select this page (up to 25) selects visible review items; Approve selected, Exclude selected, and Mark selected as Short apply explicit decisions.
2.1.3.8 Individual and bulk actions can differ from the global strong-preview publication action.
2.1.3.9 Notes and review history remain recorded.
2.1.3.10 Expand Automatic discoveries, Member contributions, Content reports & member mutes, Review history & recovery, or Discovery tools & settings to reach the relevant controls. These sections keep the queue compact.
2.1.3.11 Verify the uploader as well as the performer: Missioned Souls performing on its official channel is an official upload, not a reactor reaction. Existing exclusions must remain protected during imports, rechecks, and restoration.

#### 2.1.4 Submissions, comments, content reports, and mutes

2.1.4.1 Refresh review queue reloads community submissions, comments/replies, and relevance reports.
2.1.4.2 Accept or reject with an explanatory note after checking evidence.
2.1.4.3 Accepting a verified removal report excludes the catalog match; accepted verified new submissions publish a Confirmed match when eligible; choose their format during approval.
2.1.4.4 Relevant respectful criticism is allowed regardless of its rating.
2.1.4.5 Content reports & chat moderation offers Dismiss report (no content removal), Hide content, or Hide & mute 24h.
2.1.4.6 Temporary mutes lists current restrictions; Unmute removes one.
2.1.4.7 Moderators should not approve their own submissions for points.
2.1.4.8 Keep existing exclusions unless there is a deliberate, supported correction.

#### 2.1.5 Member Review: grant or revoke trust

2.1.5.1 Open Member Review and choose Ready for trust review to see unreviewed members with at least three independently moderator-approved contributions. Use All members to revisit a deferred or revoked member; Trusted members lists existing trusted access.
2.1.5.2 Expand Review contributions and trust history and click Load evidence. Check the member’s accepted contributions, video links, moderator notes, accuracy and conduct. The approved count includes all qualifying records; the evidence list shows the latest 100.
2.1.5.3 Select Grant Trusted Member status, enter a reason, then Save member change. At least three accepted contributions verified by another moderator are required. Members cannot grant or change their own trust.
2.1.5.4 Choose Reviewed: keep approval required to defer trust with a reason, or Revoke Trusted Member status to remove direct posting. Every trust decision is recorded in trust history. A later moderator review can grant trust again when the three-approval condition is met.
2.1.5.5 Trusted posts publish directly without an additional reputation-verification action. Continue reviewing uncertain matches, correction/removal requests and content reports. Mutes still prevent posting.

### 2.2 Catalog and recovery

#### 2.2.1 Find reviewed submissions and reopen a rejection

2.2.1.1 Open Moderator Queue → Member contributions → Reviewed submission history. Choose Accepted and rejected, Rejected, or Accepted; search by direct YouTube link, video ID, explanation, or review note.
2.2.1.2 Use Search history and Previous history / Next history to browse reviewed records. A rejected submission may exist here even if it was never added to the catalog, so Correct video information cannot load it.
2.2.1.3 For a rejected submission, verify the video, enter Reason for reopening, and select Reopen for Review. The submission returns to Submitted reactions for metadata fetching and a new review.
2.2.1.4 Reopening does not publish a video, remove a catalog exclusion, or award points. Review the returned pending submission and choose Accept or Reject with a note. Existing catalog exclusions must be resolved separately.
2.2.1.5 For a saved catalog video that is rejected or excluded, use Correct video information and the deliberate Save Corrections & Restore workflow instead. Accepted submissions have no Reopen for Review button.

#### 2.2.2 MS Journey: maintain videos and categories

2.2.2.1 Open MS Journey → Catalog updates & category review. Refresh official YouTube catalog starts an official-upload scan; repeat refresh to continue it. Scheduled batches continue initiated scans after reaction discovery, then refresh counts daily after a completed pass.
2.2.2.2 Each refresh scans up to 200 uploads and retains a continuation cursor. It needs the existing server-side YOUTUBE_API_KEY. Facebook and other sources require manual entries or imports; YouTube refresh cannot collect them.
2.2.2.3 Use Add Facebook / other video or Review categories & details. Edit title, dates, categories, availability, counts, Statistics recorded at, and Source / review note; select Categories reviewed after checking assignments. Keep the same video URL while editing; add a separate record for a different video.
2.2.2.4 Mark as Short and Remove Shorts tag deliberately set a persistent format choice. The editor’s This video is a Short checkbox does the same. Automatic refreshes retain that choice and reviewed categories; a short duration alone does not prove a Short.
2.2.2.5 Use Import catalog JSON for a video array or an object with videos, under 2 MB and 1–1,000 entries per import. Export catalog downloads the current archive for review or reuse. This JSON archive import is separate from the reaction master workbook import.
2.2.2.6 Under Categories, Add category creates a category; Rename changes its label; arrow buttons reorder it; Archive hides it from browse navigation; Restore makes it visible again. Existing video assignments are preserved.
2.2.2.7 Shorts is a fixed format category and cannot be renamed or archived. Existing archived assignments remain available when editing those videos. If another moderator changes categories concurrently, reload before retrying.
2.2.2.8 View-growth rankings need dated snapshots. Facebook/other-source counts must be entered or imported, and current totals alone do not establish historical growth.
2.2.2.9 Sync official playlists refreshes the official-playlist browse categories. By year collections follow publication dates. The magnifying-glass button reveals member search, year, source, and collection filters; Include Shorts and Clear filters remain beside results.
2.2.2.10 Official uploads belong in MS Journey, not as confirmed reaction matches. A labeled official card in My Feed is a feed projection, not evidence that the upload is a reaction. Do not restore excluded official uploads as reactions.
2.2.2.11 Visibility decisions survive official-channel refreshes and repeated imports. Hide from members keeps a video in the catalog but removes it from member browsing; Remove from MS Journey removes it from this catalog, not YouTube; Restore to MS Journey makes it visible again.

#### 2.2.3 Import a master workbook

2.2.3.1 Open Moderator → Import Workbook and choose a reconciled .xlsx master smaller than 10 MB. Updated Master supplies channels; the newest Video Import YYYY-MM-DD sheet supplies videos.
2.2.3.2 Select Preview import. Review new records, already present matches, excluded / rejected matches, protected records, and items needing review. Previewing does not change the catalog.
2.2.3.3 Select Import new records to apply missing records after a fresh comparison with the live catalog. Existing decisions and exclusions remain protected; uncertain new records are Pending for moderator review.
2.2.3.4 Read or Download receipt and use Recent imports to review previous receipts. Repeating an applied import returns its receipt; uploading again skips existing IDs.
2.2.3.5 Previews expire after 24 hours. Re-upload for a fresh preview. Unsupported layouts and conflicting IDs produce an error; identical duplicate rows are collapsed. The limit is 1,000 channels and 1,000 videos.
2.2.3.6 Imports preserve existing titles, formats, comments, ratings, account data, availability, and historical scan progress. Deploying the import tool does not automatically import a workbook.

#### 2.2.4 Reconcile missing reaction video IDs

2.2.4.1 In Import Workbook, open Reconcile missing reaction videos. Paste up to 100 video ID,channel ID pairs, one pair per line.
2.2.4.2 Load 74 audited missing IDs loads candidates from the October 5 audit. These are candidates to check, not 74 verified reactions or a guarantee that all remain missing.
2.2.4.3 Select Check and reconcile to fetch current public YouTube details. Clear matches become Confirmed; known performer matches with uncertain reaction evidence or possible Shorts become Pending.
2.2.4.4 Existing matches, exclusions, unavailable videos, channel holds, and ID conflicts are preserved. Unrelated or nonpublic entries are recorded without publication; description-only uncertain matches remain in the receipt for investigation.
2.2.4.5 Inspect and download the receipt. Repeat safely by exact, case-sensitive video ID. If an interrupted request has no completed receipt, retry and inspect its result.
2.2.4.6 This checks explicit video IDs. It does not reconstruct historical reaction totals or reset history cursors. Use Correct video information for an existing excluded or rejected match that should deliberately be restored.

#### 2.2.5 Classification and member review

2.2.5.1 Open Video Classification Review for the Unknown format and Probable reaction lists.
2.2.5.2 Check the video on YouTube, select Short or Full-length, tick the verification box, and confirm.
2.2.5.3 Use Member Review under Moderator to search names or email, correct display names, adjust points with a reason, or mute and unmute posting.
2.2.5.4 New members are Novice until 25 points, then Contributor. Badges appear before member display names: Novice (0–24), Contributor (25–99), Reaction scout (100–249), Catalog curator (250–999), and Community champion (1,000+). Hover over a badge to see its level and current points. The Points & Trust page shows the badge legend. Badges use Contribution Points and reflect adjustments or reversals on refresh. Trusted Member status is separate and granted by moderators.

#### 2.3.4 YouTube connection configuration and troubleshooting

2.3.4.1 The current import uses a server-side Google redirect flow with read-only offline subscription permission, separate from member sign-in. Configure a dedicated Google OAuth Web application client and enable YouTube Data API v3.
2.3.4.2 Configure GOOGLE_YOUTUBE_CLIENT_ID and the exact HTTPS YOUTUBE_OAUTH_ORIGIN. Authorize the exact redirect URI ending /api/youtube/subscriptions/callback. A JavaScript origin alone is insufficient. Keep production and staging configurations separate.
2.3.4.3 Store GOOGLE_YOUTUBE_CLIENT_SECRET and YOUTUBE_TOKEN_ENCRYPTION_KEY as server secrets. Never put them in source, browser settings, support messages, or screenshots. Preserve the encryption key for recovery; replacing it without re-encryption makes existing connections unreadable.
2.3.4.4 Check Google consent-screen status, allowed accounts, redirect URI, scope, and verification requirements for authorization errors. Domain ownership alone does not approve OAuth access. Consult docs/youtube-subscriptions.md for the supported configuration and retention behavior.
2.3.4.5 The server checks connections daily in bounded batches and before preview/import. Revocation or scope loss removes tracked imported follows. Temporary provider errors do not immediately purge them; connections unverified for 25 days are removed. Monitor scheduled checks and revocation retries.
2.3.4.6 Unfollow and reset clear tracked provenance; saved groups exclude tracked imported follows. Keep the public overview, import disclosure, Privacy Policy, and disconnect behavior consistent. Subscription requests consume the OAuth project’s applicable YouTube quota.

#### 2.3.5 Recheck previews and strong matches

2.3.5.5 Strong matches accept an exact performer name in the title, or reaction wording in the title with explicit performer reaction evidence in the description. Covers, Shorts and missing duration do not block approval. Watch parties, tour updates and comparison titles await review.

2.3.5.7 Publish up to 50 strong preview matches applies up to 50 fresh eligible strong results across the queue, not just checked rows or the visible page.
2.3.5.8 It preserves exclusions and protected decisions.
2.3.5.9 Preview eligibility can expire or change; a zero result means no eligible current matches.
2.3.5.10 Shorts/unrelated suggestions remain for explicit review.

### 3.1 Configuration and release

#### 3.1.1 Administrator configuration and deployment

3.1.1.1 In Cloudflare, the reactionsignal Worker uses D1 binding DB for reaction-signal-catalog.
3.1.1.2 The scheduled trigger is */15 * * * * (every 15 minutes).
3.1.1.3 YOUTUBE_API_KEY must be a secret; never paste it into public source, chat, or screenshots.
3.1.1.4 SUPABASE_URL and SUPABASE_PUBLISHABLE_KEY configure authentication; never substitute a privileged service-role key in browser configuration.
3.1.1.5 COMMUNITY_MODERATOR_EMAILS designates moderator email addresses; MEMBER_EMAIL_ALLOWLIST restricts invited access when configured.
3.1.1.6 YOUTUBE_PUSH_CALLBACK_URL must be the public website origin followed by /api/youtube/push.
3.1.1.7 Connect / renew channel notifications renews channel subscriptions; received notifications still require API checks and matching.
3.1.1.8 DISCOVERY_DAILY_SEARCH_LIMIT currently limits performer searches to 20/day; other API calls and other scripts using the Google project also consume applicable quota.
3.1.1.9 Google Cloud’s YouTube Data API quota page is the source for actual quota usage.
3.1.1.10 In Supabase Authentication, maintain the Site URL and permitted redirect URLs and enabled email/Google providers.
3.1.1.11 Domain changes require checking these settings and the callback URL.
3.1.1.12 Use the guarded npm run deploy release command from the current checkout. Review the exact source scope, rebuild and pass release checks, then verify the deployed build identity and signed-in member experience. Apply database migrations separately when they are required and authorized; do not publish a legacy Worker download or deploy files from tmp/.
3.1.1.13 Keep applied migrations, add new ones, and inspect the build log before hard refreshing. npm run build must produce dist/server/index.js. For a manual preview, use npm run deploy:preview so the Worker is built before preview upload.
3.1.1.14 Cloudflare database metrics show row reads/writes; database quota, worker capacity, YouTube quota, and sign-in provider limits are separate checks.
3.1.1.15 A successful deployment does not guarantee healthy discovery: verify recent runs, catalog loading, login, and moderation.
